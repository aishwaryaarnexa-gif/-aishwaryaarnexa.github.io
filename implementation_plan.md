# Plan: 5-Page Trekking & Villa Booking Website

## Pages:
1. index.html - Home (hero, about, stats, featured treks/villas, testimonials, CTA)
2. treks.html - Trek Packages (filters, cards, details)
3. villas.html - Villa Packages (filters, amenities, gallery)
4. booking.html - Booking form (date picker, guests, package selection, billing)
5. payment.html - Payment gateway (card/UPI/netbanking, OTP, confirmation)

## Key Features:
- Glassmorphism dark/nature theme
- Animated hero with particle effects
- Multi-step booking form
- Simulated payment gateway (UPI, card, netbanking)
- Booking confirmation with receipt
- Smooth page transitions
- Responsive navigation
